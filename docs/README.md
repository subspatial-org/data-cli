# subspatial command-line documentation

These pages explain how to use `subspatial`. The [main README](../README.md) covers installing it and signing in for the first time.

- [Getting started](getting-started.md): references, finding a repository, browsing, downloading, and committing your first file.
- [Repositories](repositories.md): list, create, fork, archive, delete and restore repositories.
- [Files](files.md): browse, download, upload, commit, prefetch and refresh.
- [Collaboration](collaboration.md): branches, pull requests and releases.
- [Mounting](mount.md): see a repository as a folder (Linux, experimental), and the non-kernel alternative.
- [Authentication](authentication.md): signing in, tokens, where settings are stored, and expired logins.
- [Command reference](command-reference.md): every command, argument and flag.
